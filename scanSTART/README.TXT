========================================================================
ScanSnap 自動スキャン＆PDF変換スクリプト 仕様説明書 (README.TXT)
========================================================================

【概要】
本スクリプトは、ScanSnap Home Web SDKのローカルAPIを利用して、PCに接続
されたScanSnapからワンクリックでスキャンを実行し、取得したデータを自動的
にPDF形式に変換して保存するWindows向けの自動化ツールです。

スキャン実行時に表示されるScanSnap Homeの警告ウィンドウに対し、Windows API
を利用して自動的に「Alt+Y」を送信し、操作を自動で続行させる「警告バイパス
機能（マルチスレッド監視）」を標準搭載しています。


------------------------------------------------------------------------
1. 主な機能と特徴
------------------------------------------------------------------------
■ SDK自動接続（ポート探索）
  ScanSnap Homeが使用するローカルポート（45537〜45551）を自動で探索し、
  有効なセッションIDを自動取得します。

■ 警告ウィンドウの自動クリック（バイパス機能）
  別スレッドで「ScanSnap Home」の警告ウィンドウを0.1秒間隔で高速監視。
  ウィンドウ検知後、最前面化を試み、確実にボタンを押下させるために
  「Alt+Y」キーの強制疑似入力を実行します。

■ スキャン設定（固定値）
  ・ファイル形式：PDF（※内部的にはJPGで受信後、変換）
  ・圧縮形式：JPEG圧縮（レベル5）
  ・画質モード：ファイン（2）
  ・カラーモード：カラー（1）
  ・読み取り面：両面（0）

■ PDF自動変換・クレンジング
  SDKから受信した生の画像データ（JPG）を保存後、自動で本物の「PDF」に
  一括変換します。変換が正常に成功した場合は、元のJPGファイルを自動削除し、
  保存先フォルダ内をクリーンに保ちます。


------------------------------------------------------------------------
2. 動作環境・前提条件
------------------------------------------------------------------------
■ OS
  Windows 10 / 11 (Windows APIを使用するため、Windows環境専用です)

■ 必須ソフトウェア / ドライバ
  ・ScanSnap Home および ScanSnap Home Web SDK サービスが起動していること

■ Python環境・必要ライブラリ
  ・Python 3.x
  ・requests ライブラリ (HTTP通信用)
  ・Pillow (PIL) ライブラリ (PDF変換処理用)
    ※Pillowが未導入の場合、JPGファイルの保存のみ行われ、PDF変換はスキップされます。

  [ライブラリのインストールコマンド]
  pip install requests pillow


------------------------------------------------------------------------
3. コマンドライン引数（パラメータ）仕様
------------------------------------------------------------------------
本スクリプトは、実行時に以下のパラメータ（引数）を受け付けることができます。

■ 第1引数：保存先フォルダの指定（任意）
  記述例: python script_name.py "D:\ScanData"
  ・指定されたフォルダが存在しない場合は、実行時に自動で作成されます。
  ・省略した場合は、デフォルトの「C:\scan」に保存されます。

■ 第2引数以降：非対応
  ・第2引数（およびそれ以降のパラメータ）を設定して実行しても、
    スクリプト側で処理されないため、すべて無視されます。


------------------------------------------------------------------------
4. 処理フロー（システム内部の動き）
------------------------------------------------------------------------
1. [初期化] 保存先フォルダの存在確認・作成。
2. [監視始] 警告ウィンドウを検知するバックグラウンドスレッドを起動。
3. [SDK接続] 45537番ポートから最大15ポートを走査、セッションIDを確立。
4. [スキャン要求] SDKに対してAPI経由でスキャン開始を命令。
   ↳ (この間に警告が出た場合、裏の監視スレッドが自動で Alt+Y を送り突破)
5. [データ回収] スキャン完了後、生成された画像データをバイナリ(Blob)で取得。
6. [変換・削除] JPGとして一時保存 ➔ PillowでPDFに変換 ➔ 元のJPGを削除。
7. [終了] スキャン成否に関わらず、監視スレッドを確実に安全停止。


------------------------------------------------------------------------
5. 主要なエラー・デバッグログ
------------------------------------------------------------------------
コンソールに出力される主なメッセージの仕様です。

・"DEBUG: 警告ウィンドウの監視を開始しました..."
  ➔ バックグラウンドで自動クリックシステムが正常に動作しています。

・"⚠️お知らせ: Pillowライブラリが未導入のため、PDFへの変換はスキップしました。"
  ➔ スキャン自体は成功していますが、PDFに変換するためのライブラリが不足しています。
     Pillowをインストールしてください。

・"Error: ScanSnap Home Web SDKサービスに接続できませんでした。"
  ➔ ScanSnap Homeが起動していないか、SDKサービスが有効になっていません。
     タスクトレイ等で常駐状態を確認してください。


------------------------------------------------------------------------
【免責事項・注意】
本スクリプトはWindows APIを利用したキーイベントの疑似送出を行っています。
実行中に別の重要なウィンドウ操作を激しく行っている場合、キー入力（Alt+Y）が
予期せぬウィンドウに送られるリスクが極めてわずかですが存在します。
スキャン実行中は、極力他のキーボード操作を控えることを推奨します。
